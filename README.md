# Diablo IV Toolkit — Fishing Tracker

Minimalistic, Diablo-themed fish tracker for Diablo IV (Season 15 / patch 3.2.x).
All 123 fish, grouped by region, with checkboxes that persist in your browser.

## Use

Open `index.html` in any browser — no build step, no dependencies. Progress is
stored in `localStorage` on the machine you browse with.

Or use it hosted: **[GitHub Pages](https://akaizoku.github.io/d4tk/)** once enabled.

## Features

- All 123 collectible fish: 5 Sanctuary-wide, 16 per region × 7 regions, 5 Mythic Uniques, and the Khanduras Red Herring
- Per-region and global progress bars, plus a "regions complete" counter
- Search, "hide caught" filter, collapsible regions, and a reset action
- Progress saved locally, so the checklist survives reloads (unlike IGN's)

## Data

Fish names, regions, rarities and Mythic fish waters follow the in-game
collection as documented by community databases (Season 15, patch 3.2.x).
Unofficial fan-made tool; not affiliated with Blizzard.
